# Retail Data Engineering Project

This project implements an end-to-end retail data engineering and analytics pipeline using Python, Pandas, Jupyter Notebook and Power BI.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- VS Code
- Power BI

## Project Features

- Data Ingestion
- Data Quality Checks
- Data Cleaning
- Data Transformation
- Product Dimension Merge
- KPI Generation
- Interactive Power BI Dashboard
